# Demo recording

The canonical demo is generated by the repository rather than performed manually. It creates an isolated temporary Git repository and demonstrates the complete trust-gate story without network access or a model API:

1. Initialize ProjectMind and declare one login requirement.
2. Show that a passing but unbound test remains `NOT_VERIFIED`.
3. Bind the exact configured command and testcase, then obtain `VERIFIED` plus a ProofPack.
4. Break login behavior and show that the previous success is not reused: the result returns to `NOT_VERIFIED`.

## Run or record

For a fast validation run:

```bash
pnpm demo
```

For screen recording, use a large terminal with a clean prompt and add a short pause before each command:

```bash
pnpm demo --pace 900
```

Record the full terminal window from the title through `Demo complete`. Do not cut out either failed verdict: they establish the fail-closed behavior. The expected final summary is:

```text
Observed: NOT_VERIFIED -> VERIFIED -> NOT_VERIFIED
Every verdict came from fresh, explicitly bound repository evidence.
```

Use `--keep` only when inspecting the generated fixture; it prints and preserves the temporary directory. The normal command removes it and never prints machine-specific paths, keeping the recording reproducible.
